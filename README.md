# MTN-CUSTOMER-CHURN
This project aims to analyze and predict customer churn for MTN, a telecommunications company. The goal is to identify which customers are most likely to stop using MTN’s services, understand the factors behind customer attrition, and provide actionable insights to reduce churn and retain customers.
# OVERVIEW
Understand and predict which customers of MTN are likely to churn (i.e. leave MTN service), and also identify the key factors that lead customers to churn.
Provide actionable insights so that MTN can take intervention steps (offers, improved service, etc.) to reduce churn and retain customers.
